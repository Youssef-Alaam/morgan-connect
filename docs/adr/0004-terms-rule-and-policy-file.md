# No known terms breach; grey routes are opt-in; a policy file records every route

Decided 24 Nov 2026 (grill decisions 9, 15, 55). Morgan Connect offers a provider route only when the provider's own terms allow it. A route that is grey (not clearly allowed, not clearly banned) is off by default, labelled as such, and needs the admin to switch it on after a written risk notice. Where no legal route exists the product says so and offers none. Every credential belongs to one person and is never used for anyone else.

A policy file lists each route with its verdict, source link and last-verified date, and can switch a route off without a release.

## Considered Options

- Warn and allow (the original decision 3): leaves users exposed to account bans.
- Zero grey routes: would remove WhatsApp, which the owner needs.

## Consequences

Claude and Gemini run on API keys only. Subscription sign-in exists for ChatGPT, Copilot and Cursor, each for the subscriber alone. Terms must be re-read before every minor release; a route unverified for 90 days switches itself off.
