# Name Check: "Morgan Connect"

Checked 2026-11-24. The web lookup was done by Gemini; the GitHub and npm lines were re-checked directly (HTTP 404 on each address). The trademark and product findings come from Gemini's search and were not opened one by one. This is not legal advice or a formal trademark clearance.

## Verdict: the handles are free, the name is crowded

| Where | Result |
|---|---|
| GitHub `morgan-connect`, `morganconnect` (user or organisation) | **Free** (verified, 404) |
| npm `morgan-connect`, `morganconnect`, scope `@morgan-connect` | **Free** (verified, 404) |
| Registered trademark "MORGAN CONNECT", software classes 9 / 42, USPTO / EUIPO / WIPO | None found in search results; not a formal search |
| USPTO application "J.P. MORGAN CONNECT" (serial 87353994, filed 2017, JPMorgan Chase Bank) | Reported **abandoned** |

## Others already using the name

| Who | What |
|---|---|
| JPMorgan Chase | "J.P. Morgan Connect": a live commercial banking and treasury platform, with a mobile app |
| Morgan International | "Morgan Connect": a careers and networking web platform |
| Morgan Connect Limited | A company on the UK register |
| Morgan Stanley | "StockPlan Connect" (near match, registered mark) |
| Morgan & Morgan | "The Morgan Connection" (near match) |

## What this means

- Nothing blocks creating the repo or the npm package today.
- The practical costs are two. Searching "Morgan Connect" will show a bank first, so the project is hard to find by name. And a global bank using almost the same name for software is the kind of owner that sends letters, even with its own application abandoned; an open-source personal agent is far from banking, which lowers the risk but does not remove it.
- If the owner wants a name with less company, this is the cheapest moment to change it: before the repo, the first video and the first commit.

## Still to do if the name is kept

- Search the exact name in the WIPO Global Brand Database and EUIPO eSearch plus.
- Reserve the GitHub organisation and the npm scope on the same day the repo is created.

Emotional Computing is a small owner in *the same field with the same product description and the same first name*. That affects every name that contains "Morgan" (Morgan OS, Morgan Connect, Morgan Relay), not only this one: a personal AI agent called "Morgan <anything>" will be read as theirs or as a copy of theirs.
